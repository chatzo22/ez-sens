# EZ Sens
Original single-file browser aim trainer + sensitivity finder for CS2, THE FINALS and ARC Raiders.
Open `index.html` in Chrome/Edge (desktop). Math checks: `node test/math.test.js`.
Yaw: CS2 0.022 (verified), THE FINALS 0.001 (community-measured), ARC Raiders 0.00136101 × FOV/70 (community-measured).
Not affiliated with Valve or Embark Studios.
