About EZ Sens

An original, independent tool. Not affiliated with Valve or Embark Studios.

The math

degrees per count = yaw × sens · cm/360 = 914.4 ÷ (DPI × sens × yaw) (914.4 = 360° × 2.54 cm/in) · eDPI = DPI × sens. Converting keeps cm/360 the same: sens_B = sens_A × yaw_A ÷ yaw_B.

How scoring works

  • Flick / micro: score = 100 × accuracy × (500 ms ÷ avg time-to-kill), capped. Overshoot / undershoot is judged at the first point your crosshair settles after each flick: past the target along the flick direction = overshoot, short of it = undershoot.
  • Tracking: score = % of time on target. Crosshair ahead of the target's motion = overshoot, behind = undershoot.
  • Finder: quadratic fit of score vs log(cm/360), clamped to the tested range, then up to ±6% toward slower if you overshoot / faster if you undershoot.

Limitations

  • Raw input needs Chrome/Edge's unadjustedMovement pointer lock. If the browser refuses it, Windows pointer speed / acceleration can change the feel (set Windows to 6/11 and turn off "Enhance pointer precision").
  • THE FINALS and ARC Raiders yaw values are community-measured, not published by Embark. Check with one full 360° turn in-game.
  • THE FINALS accepts whole numbers only, so a converted value is rounded. ARC Raiders' decimal support is unconfirmed — the rounded value is a whole number to be safe.
  • ARC Raiders is third-person; this arena is first-person. Vertical sens is treated as equal to horizontal.
  • Arena FOV only changes what you see, not the turn distance. THE FINALS' default FOV is not verified here, so its arena preset (103° horizontal) is approximate.
  • A recommendation from one session is noisy. Run the finder 2–3 times on different days and use the average.
